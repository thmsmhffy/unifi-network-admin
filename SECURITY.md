# Security policy

Do not open a public issue for a credential leak, authorization bypass, cross-origin request, unsafe mutation, or sensitive inventory disclosure.

Report vulnerabilities through [GitHub's private security advisory form](https://github.com/thmsmhffy/unifi-network-admin/security/advisories/new). Do not disclose a vulnerability in a public issue.

Supported security fixes target the latest release. v0.1 is read-only and must stay read-only at the transport, CLI, and MCP layers.
